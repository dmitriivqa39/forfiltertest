How to read the results

  • Every probe is a fetch(), which browser devtools list as XHR. All probes start during page load, concurrently.
  • Same-origin probes resolve against the page URL and point at files that need not exist. An HTTP 404 still proves the request was made and was not blocked.
  • Cross-origin probes use mode: "no-cors", so a completed request reports an opaque response.
  • cache: "no-store" keeps every reload identical: the same URLs hit the network again instead of coming from cache.
