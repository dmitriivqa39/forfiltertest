AdGuard DNT & GPC Signal Check

Detects the Do-Not-Track (DNT) and Global Privacy Control (Sec-GPC) signals that the AdGuard extension sends on network requests — not the browser's own settings.

Signal check — what AdGuard actually sends

The page makes a request to an echo service and inspects the headers that reach it. AdGuard's Tracking protection (Stealth Mode) injects these headers, so this is where its signals appear.

On the server, read the headers the same way:

// Node.js (Express)
const dnt = req.headers['dnt'];       // "1" | "0" | undefined
const gpc = req.headers['sec-gpc'];   // "1" | undefined
// PHP
$dnt = $_SERVER['HTTP_DNT']     ?? null; // "1" | "0" | null
$gpc = $_SERVER['HTTP_SEC_GPC'] ?? null; // "1" | null

Both signals are voluntary — they ask, but nothing forces a site to honor them. GPC is legally binding in several US states; DNT is deprecated and largely ignored.

Runs entirely in your browser. Nothing is stored; only the echo check above makes a network request.
